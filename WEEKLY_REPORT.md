# Единый отчёт

GET `/api/storage/report` с обычным Bearer SYNC_API_KEY. По умолчанию 7 ночей начиная с сегодняшнего дня по Москве. Параметры: `date_from` (YYYY-MM-DD), `nights` (1–31).

Загрузка и бронирования за 24/72/168 часов вычисляются из одной согласованной транзакции PostgreSQL. В каждом дне и категории: занято, свободно, сумма размещений до налогов, новые активные номера по окнам, цены всех десяти тарифов по размещениям и расчётные рекомендации. Окна вложены, складывать их нельзя. Это текущие активные брони по времени создания, не чистый прирост с учётом отмен.

Цены — снимок экспорта TravelLine от 02.11.2026 09:26 МСК за 02.11.2026–02.02.2027 включительно. Обновление бронирований не обновляет тарифный снимок. Дата экспорта явно указана отдельно. Ремонтные блоки пока исключены.

Endpoint только читает базу, не запрашивает и не изменяет тарифы TravelLine. Темп бронирований показан как контекст и не влияет на формулу рекомендаций. При неполноте или устаревании данных рекомендации удерживаются. Неполные счётчики создания помечаются `new_active_rooms_complete=false`.
